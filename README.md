# 个人影院

个人影院是一个 Android 电视播放器，桌面和 Leanback 启动器上显示的名字是个人影院。包名仍是 `app.jianxia.tv`，已安装的版本可以直接覆盖升级，接口、设置和播放记录都会保留。安装包里没有点播片源，也没有把频道表打进去。第一次打开时会加入一份公共直播「公共频道（iptv-org）」，频道列表在使用时从 [iptv-org](https://github.com/iptv-org/iptv) 在线获取，默认是中国，可以更换、停用或删除。点播接口仍然只能自己添加。

界面文字为简体中文，可以用遥控器完成全部操作。

## 下载

优先安装 **`geren-yingyuan-universal.apk`**。很多盒子是 64 位芯片、32 位系统，只含 arm64 的安装包会装不上；通用包里同时有 32 位和 64 位库，系统会自己选。

另外两个是按架构拆开的，只有在你确定系统位数、又想少占一点空间时再用：

- `geren-yingyuan-armeabi-v7a.apk`：32 位系统
- `geren-yingyuan-arm64-v8a.apk`：64 位系统

最低系统为 Android 5.0（API 21）。安装包是 release 混淆后的体积。从 0.4.5-beta 起，三份安装包使用同一份发布证书，证书 SHA-256 为 `46:79:EF:51:7E:33:5C:87:B5:DE:63:EC:7B:89:AA:22:67:6F:96:0E:E7:8F:0D:71:AC:AA:20:45:57:5C:67:21`。带连字符的版本（例如 `v0.3.1-beta`）是预发布版本。内置了 VLC 的原生库，安装包会比早期版本大。

0.5.0-beta 继续用 0.4.5 的同一把发布证书，可以覆盖安装 0.4.6。爬虫原生库改到应用私有目录，先删除旧文件再经临时文件写入，避免只读的 `ftyguard_v7.so` 再次打开时出现 EACCES。首页改成站源、分类和海报网格，不再使用左侧导航。搜索没有片源时直接说明原因，播放超过 18 秒没有画面会换线路。

0.4.5-beta 只改了签名。v0.4.4 及更早的每个构建都用了一把新的调试证书，所以不能互相覆盖安装。第一次安装 0.4.5 需要先卸载旧版；之后的版本用同一把证书，可以覆盖安装并保留数据。密钥库在 `signing/geren-yingyuan-release.pkcs12`，口令在 `signing/release.env`。GitHub Actions 的密钥接口返回 403，无法写成仓库密钥，因此文件进了这个公开仓库。任何人都能用它签出可以覆盖安装的包。

0.4.4-beta 修了真机上的几件事。32 位电视默认改用 ExoPlayer，VLC 起不来会自动换内核再换线路，崩溃堆栈会留在「设置 > 关于」，也可以在手机扫码页看到。饭太硬这类自带 Init 的 JAR 会用 JAR 自己的类和原生库，不再被宿主的空类挡住；站点状态按每个站点只计一次，并写出真实异常。虎牙、斗鱼等直播类站点默认不出现在影片页，设置里可以打开「在影片页显示直播类站点」。豆瓣海报会带上 Referer，并走和接口一样的 DoH。爬虫要调用的 Gson、OkHttp、jsoup 会保留原来的类名。详情页选集按 40 集一页，播放键位更接近影视仓：确认键暂停并呼出控制条，上键选集，下键换线，菜单键打开倍速、画面、内核、解码、片头片尾、字幕、弹幕和换源。

0.4.3-beta 把用户看到的名字从 TV NET 改成「个人影院」，包括启动器名称、图标和电视横幅、首页标题和导航、影院大图在没有片名时的占位、关于页、设置里的外观预览、备份剪贴板标签，以及手机扫码页的标题。安装包文件名是 `geren-yingyuan-universal.apk`、`geren-yingyuan-armeabi-v7a.apk`、`geren-yingyuan-arm64-v8a.apk`。包名仍是 `app.jianxia.tv`，覆盖安装会保留原来的接口和设置。

0.4.2-beta 的筛选页只有五行：精选标签、年代、地区、类型、排序，下面是带评分的海报。没有「风云榜」和「新片预告」。列表来自豆瓣公开接口，走和 0.3.0 一样的豆瓣代理设置。选中一部后，会在你已经添加的接口里搜索并打开，不播放豆瓣上的片源。站点状态里，可用的苹果 CMS 或爬虫如果配置了 `filters`，可以用同一套芯片筛选该站点，选中后直接打开详情。

0.4.1-beta 先放上了筛选页，并在顶部加了「风云榜」和「新片预告」。0.4.2 去掉了这两项。

0.4.0-beta 可以在设置里打开 JAR / JS 爬虫。这项默认关闭，打开前会要求确认：这会下载并运行配置里的远程代码，可能访问网络和应用数据。关掉之后会立刻停止执行。站点状态页会显示每个爬虫是可用还是失败。JS 引擎是 QuickJS（Apache-2.0）。安装包里仍然没有点播片源，也没有写死任何配置地址。

0.3.2-beta 会在首页没有海报时说明原因，例如「共 N 个站点：X 个可用，Y 个是爬虫（JAR/JS）未打开，Z 个加载失败」，并可以查看每个站点的结果。苹果 CMS 在 `ac=list` 没有条目时会再请求 `ac=videolist`。

0.3.1-beta 把用户看到的名字从「简匣」改成 TV NET，包括启动器名称、电视横幅、首页标题、关于页和手机扫码页。包名没有改。

0.3.0-beta 增加了豆瓣评分和短评、豆瓣分类浏览、m3u8 广告切片过滤、用户自备的 danmu_api 弹幕，以及外挂字幕。豆瓣分类、播放列表改写和弹幕接口的做法参考了 [MoonTVPlus](https://github.com/mtvpls/MoonTVPlus)（MIT）。个人影院没有内置弹幕服务器，也没有内置点播片源。

## 安装

### U 盘

1. 把对应架构的 APK 拷到 U 盘。
2. 将 U 盘插到电视或盒子。
3. 用系统自带的文件管理器，或电视上已安装的文件管理器，打开 APK 并安装。
4. 如果系统提示「未知来源」，到系统设置里允许该文件管理器安装应用。

### 当贝市场 / 当贝助手

1. 电脑安装当贝助手，用数据线连接盒子，或让盒子与电脑处于同一局域网。
2. 在当贝助手里选择「安装本地 APK」，选中对应架构的 APK。
3. 安装完成后，在电视桌面的「应用」或 Leanback 启动器里打开「个人影院」。

### adb

```bash
adb connect 电视IP:5555
adb install -r geren-yingyuan-universal.apk
adb shell am start -n app.jianxia.tv/.MainActivity
```

开启电视的网络调试后，`adb connect` 才能连上。部分盒子需要先在开发者选项里打开 USB 调试或网络 ADB。

## 添加接口

首页没有点播接口时，右侧就是 **手机扫码添加**。手机和电视要在同一个局域网。页面打开后可以粘贴一个地址，也可以一次粘贴很多网址（每行一个，或和说明文字混在一起）。每个地址会单独显示「成功」「已存在」或失败原因。口令显示在电视上。

直播里默认有「公共频道（iptv-org）」。频道列表来自 iptv-org，默认打开中国列表 `https://iptv-org.github.io/iptv/countries/cn.m3u`。直播页顶部有「体育」：它把已启用直播源里分组或名称带有体育、CCTV-5、CCTV-5+、广东体育、五星体育、sports 的频道收在一起，并额外读取 iptv-org 的公共体育列表 `https://iptv-org.github.io/iptv/categories/sports.m3u`，只留下能认出的中文频道。CCTV-5 和 CCTV-5+ 排在最前。同名频道合成一条，里面的多条地址会测速后自动用较快的一条。这里不会另外加入付费体育信号。直播页可以按国家、分类（例如新闻、少儿、音乐）或语言换成 iptv-org 公布的其他列表，这些列表都是打开时再下载的。列表里标了 Geo-blocked 的频道会先灰掉；附近几个频道会做一次短探测，失败的也会灰掉，可以重试。iptv-org 若在列表头或不大的节目单索引里提供 XMLTV，会用来显示当前节目。这份节目单索引目前很大且没有可用地址时，个人影院不会整份下载。

电视上的「在电视上添加」使用应用内的屏幕键盘，可以用遥控器输入网址，也有 `http://`、`.com`、`.json` 这类快捷键。如果还是想用系统输入法，对话框里可以切换「使用系统键盘」。

手机页面和电视上的「在电视上添加」都可以一次粘贴多个网址。说明文字里的 `http://` / `https://` 会被抽出来，重复地址标成已存在，不会覆盖已有接口。整份 JSON 备份仍走「导入 / 导出」，那才会覆盖。

支持的地址：

| 类型 | 说明 |
| --- | --- |
| TVBox JSON | 常见的 `sites` / `lives` / `parses` 配置。正文可以是普通 JSON、Base64、藏在图片里的 Base64，或 `2423` 开头的密文；`//` 注释、尾逗号和 `./` 相对地址也会处理 |
| 苹果 CMS JSON | TVBox 站点 `type` 为 `1`，或直接填 MacCMS 的 `provide/vod` 接口 |
| 苹果 CMS XML | TVBox 站点 `type` 为 `0`，或直接填 XML 接口 |
| M3U / M3U8 直播列表 | `#EXTM3U` 频道列表，不是单条切片播放列表 |
| TXT 直播列表 | `分组,#genre#`，下面每行 `名称,地址`，也接受全角逗号 |
| XMLTV 节目单 | 在直播源上另填一个 EPG 地址，时间格式为 `yyyyMMddHHmmss +0800` |

可以添加多个来源，并调整顺序、单独停用。首页和搜索会并行请求所有已启用、且应用能够识别的点播站。

### 远程爬虫

TVBox 配置里 `type` 为 3 的站点可以是 JAR 或 JS。设置中的「远程爬虫」默认关闭。打开时必须点「仍然打开」，提示语是：这会下载并运行配置里的远程代码，可能访问网络和应用数据。关闭后不会再下载或执行。

打开之后，首页和搜索会请求这些站点。JAR 按配置里的 `spider` 地址下载，有 `md5` 就先校验，再按 `csp_` 类名加载。单个站点自己的 `jar` 和 `ext` 会覆盖总配置。播放地址如果是 `proxy://`，会改写到本机的代理端口。JS 使用 QuickJS，并提供 `req`、`pdfh` / `pdfa` / `pd`、本地存储、Base64、MD5，以及脚本里声明的 `import`。脚本和依赖是打开之后才下载的，没有打进安装包。

这些情况会记成该站点失败，而不会让应用退出：类名找不到、校验不一致、脚本报错、超时，或者 JAR 里的原生库和当前 CPU 对不上。下面这些没有做：

- 网页嗅探和 OCR 验证码
- 读取手机里的任意文件、`Worker` 线程
- JAR 如果还依赖 Spider / Init 以外的工具类
- 不是 0、1、3 的站点类型

解析接口里 `type` 0 的 JSON 解析地址会保留；嗅探类解析暂不执行。

## 播放

详情页会列出同一部片子在各个来源里的线路和剧集。开启「自动选线」后，应用会测量连接耗时和首包时间，能读到清晰度时也会参考，然后播放目前最快且能连通的线路。播放出错或长时间卡住时，会自动换下一条。你随时可以手动换线，这个选择会按片名记住。

默认播放内核是内置的 VLC（libVLC 3.6）。设置里的「播放器」可以改成 EXO播放器，播放菜单里也可以临时切换，这个选择会记住。如果当前内核出错，或 18 秒内没有画面，会自动用另一个内核再试一次；还是不行，才换下一条线路。站点配置里的 User-Agent、Referer 和其他请求头会带给正在使用的内核。

播放菜单里的「用外部播放器打开」会弹出系统选择框，把当前地址交给外部播放器，并尽量带上请求头。

遥控器：

- 确认键：暂停或继续，并打开控制层
- 左 / 右：按住时快退、快进，步长会逐渐加大
- 上 / 下：打开控制层；直播里用频道加 / 减或上 / 下换台
- 控制层里可以换线路、倍速、画面比例，以及这一部剧的片头片尾秒数

看过的进度会记在历史里，下次可以从上次的位置继续。一集结束前会倒计时进入下一集。

## 自己调整

设置里可以改这些项目，并随备份一起导入导出：

设置按「外观、首页、播放、接口与线路、数据与备份、关于」分组。每一项先显示当前值，按确认键再进入列表或图块，不需要手打文字。壁纸是 12 张程序生成的渐变图，也可以选纯色、不要背景，或用屏幕键盘 / 手机页面填一张图片地址。模糊和变暗用左右键调节。主题有深色、浅色、跟随系统，以及一组色块，选中后马上能看到效果。

首页默认是「影院模式」：顶部是当前焦点片子的大图、标题和播放按钮，下面是继续观看、收藏和分类横滑行。左侧导航平时只显示图标，焦点移上去再展开。设置里可以改回「经典」列表，也可以关掉动效和模糊。海报大小、栏目顺序和显示隐藏对两种布局都有效。每一组都有「恢复默认」。

手机扫码页面里的「外观」用下拉框、色块和壁纸缩略图改同一份设置。

备份是一份 JSON。电视上可以复制，手机页面可以下载或粘贴回去。导入会替换当前的全部设置和接口。

## 开发

```bash
./gradlew :core:test :app:assembleDebug
```

需要 JDK 17 或更高版本，以及 Android SDK 35。发布用的安装包在 `app/build/outputs/apk/release/`，包含通用包以及 `armeabi-v7a`、`arm64-v8a` 两个拆分包。推送 `v*` 标签时，GitHub Actions 会把这三个 APK 挂到对应的 Release 上。

`core` 模块是纯 Kotlin，单元测试覆盖 TVBox JSON、配置解码、苹果 CMS JSON/XML、M3U、TXT、结果合并和线路排序。测试夹具使用虚构片名和 `example.test`，不是可用片源。

`tools/mock-cms/server.py` 是另一个本地演示桩，用来在模拟器里看界面。它监听 `8090` 端口，同样只提供虚构内容，不会被打进安装包。模拟器里的地址一般是 `http://10.0.2.2:8090/tvbox.json`。

GitHub Actions 工作流 `.github/workflows/build.yml` 会运行单元测试、打出 release APK，并上传为构建产物。打上 `v*` 标签后，同一工作流会把安装包挂到 GitHub Release。
