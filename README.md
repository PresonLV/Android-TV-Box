# 简匣

简匣是一个 Android 电视播放器空壳。应用本身不带任何片源、直播源或接口地址，只负责读取你自己填入的配置，把多个来源的影片合在一起，并自动挑选较快的线路播放。

界面文字为简体中文，可以用遥控器完成全部操作。

## 下载

GitHub Release 里有两个安装包，按电视的 CPU 选一个即可，不必两个都装：

- `jianxia-arm64-v8a.apk`：近几年的电视、盒子和手机
- `jianxia-armeabi-v7a.apk`：更早的 32 位盒子

最低系统为 Android 5.0（API 21）。安装包是 release 混淆后的体积，用调试证书签名，证书不会提交到仓库。带连字符的版本（例如 `v0.1.0-beta`）是预发布版本。

## 安装

### U 盘

1. 把对应架构的 APK 拷到 U 盘。
2. 将 U 盘插到电视或盒子。
3. 用系统自带的文件管理器，或电视上已安装的文件管理器，打开 APK 并安装。
4. 如果系统提示「未知来源」，到系统设置里允许该文件管理器安装应用。

### 当贝市场 / 当贝助手

1. 电脑安装当贝助手，用数据线连接盒子，或让盒子与电脑处于同一局域网。
2. 在当贝助手里选择「安装本地 APK」，选中对应架构的 APK。
3. 安装完成后，在电视桌面的「应用」或 Leanback 启动器里打开「简匣」。

### adb

```bash
adb connect 电视IP:5555
adb install -r jianxia-arm64-v8a.apk
adb shell am start -n app.jianxia.tv/.MainActivity
```

开启电视的网络调试后，`adb connect` 才能连上。部分盒子需要先在开发者选项里打开 USB 调试或网络 ADB。

## 添加接口

简匣启动后是空的。进入 **设置 → 接口与直播源**。

- 在电视上直接输入地址。遥控器选字母比较慢，适合短地址。
- 用手机扫描旁边的二维码。手机和电视要在同一个局域网。页面会要求填写电视上显示的四位口令，然后粘贴地址。
- 同一个手机页面也可以导入、导出全部设置和接口。

支持的地址：

| 类型 | 说明 |
| --- | --- |
| TVBox JSON | 常见的 `sites` / `lives` / `parses` 配置 |
| 苹果 CMS JSON | TVBox 站点 `type` 为 `1`，或直接填 MacCMS 的 `provide/vod` 接口 |
| 苹果 CMS XML | TVBox 站点 `type` 为 `0`，或直接填 XML 接口 |
| M3U / M3U8 直播列表 | `#EXTM3U` 频道列表，不是单条切片播放列表 |
| TXT 直播列表 | `分组,#genre#`，下面每行 `名称,地址`，也接受全角逗号 |
| XMLTV 节目单 | 在直播源上另填一个 EPG 地址，时间格式为 `yyyyMMddHHmmss +0800` |

可以添加多个来源，并调整顺序、单独停用。首页和搜索会并行请求所有已启用、且应用能够识别的点播站。

### 还不能用的站点

需要下载并执行 JAR 或 JS 爬虫的站点（常见是 TVBox `type` 3，以及其他非 0/1 类型）会被保留并标成「不支持」，不会执行其中的代码。解析接口里 `type` 0 的 JSON 解析地址会保留；嗅探类解析暂不执行。站点目录是可插拔的，以后可以单独接入爬虫，而不必改首页和播放器。

## 播放

详情页会列出同一部片子在各个来源里的线路和剧集。开启「自动选线」后，应用会测量连接耗时和首包时间，能读到清晰度时也会参考，然后播放目前最快且能连通的线路。播放出错或长时间卡住时，会自动换下一条。你随时可以手动换线，这个选择会按片名记住。

播放器基于 Media3 / ExoPlayer，支持 HLS、DASH 和 MP4。遥控器：

- 确认键：暂停或继续，并打开控制层
- 左 / 右：按住时快退、快进，步长会逐渐加大
- 上 / 下：打开控制层；直播里用频道加 / 减或上 / 下换台
- 控制层里可以换线路、倍速、画面比例，以及这一部剧的片头片尾秒数

看过的进度会记在历史里，下次可以从上次的位置继续。一集结束前会倒计时进入下一集。

## 自己调整

设置里可以改这些项目，并随备份一起导入导出：

- 深色 / 浅色，强调色，预设渐变壁纸或一张自定义图片地址
- 首页显示哪些行、行的顺序、海报大小
- 默认来源、搜索超时、启动时进入点播还是直播
- 是否自动选线
- 解码器（硬件 / 软件）、默认倍速、默认画面比例

备份是一份 JSON。可以在电视上复制，也可以在手机局域网页面下载或粘贴回去。导入会替换当前的全部设置和接口。

## 开发

```bash
./gradlew :core:test :app:assembleDebug
```

需要 JDK 17 或更高版本，以及 Android SDK 35。发布用的安装包在 `app/build/outputs/apk/release/`，按 `armeabi-v7a` 和 `arm64-v8a` 分开。推送 `v*` 标签时，GitHub Actions 会把这两个 APK 挂到对应的 Release 上。

`core` 模块是纯 Kotlin，单元测试覆盖 TVBox JSON、苹果 CMS JSON/XML、M3U、TXT、结果合并和线路排序。测试夹具使用虚构片名和 `example.test`，不是可用片源。

`tools/mock-cms/server.py` 是另一个本地演示桩，用来在模拟器里看界面。它监听 `8090` 端口，同样只提供虚构内容，不会被打进安装包。模拟器里的地址一般是 `http://10.0.2.2:8090/tvbox.json`。

GitHub Actions 工作流 `.github/workflows/build.yml` 会运行单元测试、打出 debug APK，并上传为构建产物。
